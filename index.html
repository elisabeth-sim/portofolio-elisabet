Iya, itu 404, tapi tenang 😭. Biasanya bukan karena kode HTML-nya rusak. Dari alamat yang kamu kirim, kemungkinan besar GitHub Pages belum menemukan index.html di lokasi yang dipublikasikan. GitHub memang mensyaratkan file index.html berada di bagian paling atas dari folder sumber yang dipilih. Kita cek satu-satu ya. 1. Buka repository kamu Masuk ke repository: Repository GitHub kamu Di halaman Code, lihat daftar file. Harus terlihat seperti ini: 📁 Image 📄 index.html Bukan seperti ini: 📁 portofolio-elisabet └── index.html dan bukan: 📄 Index.html Nama harus persis index.html, huruf kecil semua. 2. Kalau index.html sudah ada Masuk: Settings → Pages Pastikan: Build and deployment Source: Deploy from a branch Branch: main Folder: / (root) Lalu Save. GitHub Pages memang bisa dipublikasikan langsung dari branch dan folder root seperti ini. 3. Cek bagian Pages Setelah disimpan, lihat apakah muncul tulisan semacam: Your site is live at... Kalau ada tombol Visit site, klik Visit site daripada mengetik alamatnya manual. GitHub menyebut perubahan Pages bisa membutuhkan waktu hingga sekitar 10 menit untuk dipublikasikan. 🚨 Tapi aku lihat ada kemungkinan typo nama repository Link yang kamu buka adalah: portofolio-elisabet Jadi repository kamu harus benar-benar bernama portofolio-elisabet. Kalau repository yang kamu buat ternyata namanya misalnya: portofolio-elisabeth maka URL-nya juga berbeda: https://elisabeth-sim.github.io/portofolio-elisabeth/ Coba buka repository GitHub kamu dan lihat daftar file-nya. Kalau bisa, kirim screenshot halaman Code repository kamu. Aku bisa langsung lihat apakah masalahnya di index.html, nama repository, atau Pages-nya. 👀 kemarin 22.08 dia berbayar ya? Nggak, Sabet 😭 GitHub Pages bisa dipakai gratis untuk website seperti punyamu. Untuk website kamu yang cuma: HTML CSS Bootstrap JavaScript sederhana gambar nggak perlu bayar hosting. Yang mungkin berbayar itu kalau kamu mau: domain sendiri, misalnya elisabeth.com hosting dengan fitur tertentu database/server khusus Tapi alamat seperti: https://elisabeth-sim.github.io/portofolio-elisabet/ bisa gratis. Jadi 404 yang tadi bukan karena harus bayar. Kemungkinan ada masalah pada index.html atau pengaturan GitHub Pages.
